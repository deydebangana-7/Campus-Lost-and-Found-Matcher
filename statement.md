## Campus Lost & Found Matcher

## Problem Statement

In a college campus, students frequently lose or find personal belongings such as bottles, ID cards, wallets, bags, books and electronic devices. Currently, identifying the owner of a found item or locating a lost item can be difficult because information is scattered among students and campus groups.

The Campus Lost & Found Matcher is a Python-based console application that allows users to report lost and found items and automatically compare their details to identify possible matches.

## Scope of the Project

The project is designed for use within a college campus. It allows users to:

* Report lost items.
* Report found items.
* Store item details in a JSON file.
* Compare lost and found reports.
* Generate a match percentage based on item details.
* View all submitted reports.

The project is currently a console-based application and does not include a web or mobile interface.

## Target Users

The main target users are:

* College students
* Faculty members
* College staff
* Campus administrators handling lost and found items

## High-Level Features

1. Lost Item Reporting
2. Found Item Reporting
3. Automatic Lost-Found Matching
4. Match Percentage Calculation
5. Report Viewing
6. Input Validation
7. JSON-based Data Storage
